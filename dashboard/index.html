About This Project

API Shield is a lightweight API security monitoring system built around a Flask backend. It detects and logs JWT-based attacks (missing / invalid / expired tokens), automated bot traffic via request-rate fingerprinting, rate-limit abuse, role-based access-control (RBAC) violations such as students attempting admin-only actions, and suspicious IPs based on repeated blocked activity. This dashboard polls the backend's /logs and /suspicious-ips endpoints to visualize that activity in real time.
